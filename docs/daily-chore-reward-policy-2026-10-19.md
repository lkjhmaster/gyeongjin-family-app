# 오늘의 할일 — 일일 전체달성 보상 정책 (2026-10-19)

## 핵심 규칙
- 자녀별, 날짜별 할일 전체가 완료되거나 부모 승인 면제인 경우에만 하루 보상을 지급한다.
- 항목별 보상 지급은 폐지한다. 하루당 승인요청 1건, 자유용돈 지급 1건만 생성한다.
- 일일 보상 = 당일 적용되는 항목의 설정 보상 합계 + 보상 미설정 항목당 100원. 기존 0원 값은 미설정으로 취급한다.
- 0개 할일인 날은 보상도 승인요청도 없다.
- 항목 완료는 당일 자녀가 표시하되 금전 지급은 부모의 하루 전체 승인 이후에만 이루어진다.
- 수행 불가 시 사유를 메모로 작성하여 면제를 요청한다. 부모가 승인한 면제는 완료와 동일하게 계산한다. 면제 거절 시 미달성으로 처리한다.
- 승인 요청 화면은 자녀별·날짜별로 'YYYY-MM-DD 할일 완료 요청' 카드 1건만 표시하고, 누르면 해당 날짜의 모든 항목(완료/면제요청/승인된 면제/미완료), 코멘트, 예상 지급액을 확인한다.
- 하루 승인 전에 할일이 모두 제출되지 않았으면 지급하지 않는다. 보류 중 면제는 미달성으로 계산한다.
- 일일 지급 식별키는 가족ID+자녀ID+일자이며 재시도·중복 승인·기기 동시 처리에도 원장에 1회만 반영한다.
- 날짜별 할일 목록과 보상금액은 최초 제출 시 스냅샷으로 보존한다. 이후 항목 변경은 과거 보상을 소급 변경하지 않는다.
- 자정 이후에도 이전 날짜의 승인요청은 남아 있어야 하며, 과거 이미 수동 정산한 데이터는 재지급하지 않는다.
- 보상 지급은 승인된 자유용돈 수입 1건과 불변 감사기록을 함께 기록한다. 달력 수입 집계에 중복 반영하지 않는다.

## 구현 검증 게이트
1. 자녀별·날짜별 스냅샷/요청 상태를 보존하고 개별 항목의 즉시 보상 지급 경로를 차단한다.
2. 승인·거절·면제 처리와 일일 지급은 서버에서 권한 및 중복을 검사하고 원자적으로 반영한다.
3. 부모 승인센터에 하루 1건 요약과 상세 화면을 제공한다.
4. 당일·전일·월말·동시 승인·중복 요청·면제 거절·0개 할일·금액 미설정 회귀 테스트를 통과한다.
5. 기존 용돈 및 할일 기록을 보존하고 Cloudflare 배포 후 서비스 응답을 검증한다.
