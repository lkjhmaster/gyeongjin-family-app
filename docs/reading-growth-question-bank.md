# 독서성장 질문 은행 (초안)

AI가 쓸 수 없거나 실패할 때 대신 쓰는 기본 질문이다. 아이의 답을 대신 쓰지 않고, 질문만 한다.
한 화면에 질문 하나, 짧게 쓰고 자동저장한다. 답은 아이의 표현 그대로 보존한다.

## 공통 흐름 (id는 reading_answers.prompt_id로 쓴다)
| id | 단계 | 질문 |
| --- | --- | --- |
| intro1 | 시작 | 이 책을 왜 골랐어? |
| intro2 | 시작 | 읽기 전에 어떤 내용일 것 같았어? |
| core1 | 핵심 | 가장 기억에 남는 장면이나 문장은 뭐야? |
| core2 | 핵심 | 그 부분이 왜 기억에 남았어? |
| me1 | 나와 연결 | 이 책 속 일이 내 경험과 닮은 점이 있어? |
| end1 | 마무리 | 이 책을 읽고 달라진 생각이나 하고 싶은 일이 있어? |
| end2 | 마무리 | 이 책을 친구에게 한 문장으로 소개한다면? |

## 초등 고학년: '왜?' 2단계
- 기본 질문(core2 등)에 답하면 후속 질문 2번.
  - why1: 방금 쓴 것에서 "왜 그렇게 생각했어?"
  - why2: "그 생각이 책의 어느 부분에서 나왔어?"
- 말투: 쉬운 말, 한 번에 질문 하나, 맞고 틀림을 따지지 않는다.
- 답이 너무 짧으면(예: 10자 미만) 고정 문장으로 이어주기: "조금만 더 말해줄래?"

## 중2: '왜?' 3단계
- why1, why2는 위와 같고 추가:
  - why3: "다른 사람은 다르게 생각할 수도 있어. 어떤 점에서 다를 것 같아?"
- 독후감 전에 쓰기 계획 질문 1개: "독후감에서 가장 말하고 싶은 한 가지는 뭐야?"
- 말투: 존중하는 짧은 말, 훈계나 평가 없이.

## 독후감 단계
- 초안은 활동 답변을 보여주며 "이 답변을 이어서 써 보자"로 시작한다. 문장을 대신 써주지 않는다.
- 부모 피드백 후 수정 요청은 질문형: "여기서 ~는 어떤 마음이었어?"

## AI 단계(2단계) 규칙
- AI는 질문 한 개만 생성한다. 답, 요약, 평가, 문장 제안은 하지 않는다.
- 실패, 한도 초과, 빈 응답은 위 질문 은행으로 자동 대체한다.
- 아이 답변은 아이 이름 없이 질문 생성에만 쓰고, 저장은 앱 DB에만 한다.
